Proposed outline: “Running the GenAI API (ascend/develop) Locally”

1. Purpose. One or two lines on what the guide covers: running the aai-bpt-genaiapi repo locally on the ascend/develop branch.

2. Prerequisites

Windows with PowerShell
Python 3.12 (the py launcher)
Git, plus access to the aai-bpt-genaiapi repo
GP VPN connected, needed for the dev DB, Redis and blob storage
The run.ps1 file with environment values, shared separately by the team

3. Get the code. Clone the repo, switch to ascend/develop, and pull the latest.

4. Create the virtual environment. py -3.12 -m venv .venv

5. Activate the virtual environment

The execution-policy command, then .\.venv\Scripts\Activate.ps1
How to confirm it worked: (.venv) appears in the prompt

6. Install dependencies. Upgrade pip, then pip install -r requirements.txt.

7. Load the environment variables. Put run.ps1 in the repo root, then run . .\run.ps1, with the leading dot.

8. Start the API. The uvicorn command and port.

9. Verify it’s running

Open Swagger at http://127.0.0.1:<port>/api/v1/docs
Check /health/live and /health/ready

10. Daily start (quick steps). For each new terminal: activate the venv, load run.ps1, start uvicorn.

11. Troubleshooting

“Python was not found”: use py instead of python
DB_string environment variable is not set: run.ps1 wasn’t loaded in this terminal
The script can’t run: the execution-policy step was skipped
DB or Redis connection errors: check the VPN
Known harmless warnings (the ALTS creds message, the deprecation warnings)

12. Security notes

Never commit run.ps1. Add it to .git/info/exclude.
Share run.ps1 only over a private channel (a Teams DM), never in a document, email thread or repo.
