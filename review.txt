The API puts the three request lists into `capabilities` (`two_by_two_generator.py:38-43`). They are Pydantic models at that point. `_build_prompt()` converts models with `model_dump()`, then JSON-serializes them (`two_by_two_generator.py:78-85`); the resulting capability JSON is included in the prompt (`two_by_two_generator.py:150-151`). The scoring prompt doesn’t directly name `High_Fit_percent`, but it does instruct the model to use provided labor-fit analysis data (`two_by_two_generator.py:145-148`).

There is a current wiring problem: the API passes `client_key` to `generate_two_by_two_analysis()` (`two_by_two_generator.py:61-63`), but the wrapper accepts `survey_ctx` and `file_ctx`, not `client_key` (`two_by_two_generator.py:881-889`). Static inspection therefore suggests this endpoint won’t successfully reach prompt construction as written.
